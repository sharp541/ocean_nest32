# OceanNest PMW3610 動作不安定問題の設計調査

## 1. 概要

OceanNest にトラックボール基板を接続した場合、PMW3360 は動作する一方、PMW3610 ではカーソルが大きくぶれる。購入した PMW3610 基板、ケース、ボールのセットは Keyball に接続すると正常に動作する。

このため、センサー基板、レンズ、ケース、ボール単体の不良よりも、OceanNest 側の電源・GND・SPI 配線またはファームウェアとの差が疑われる。

本書は KiCad データの静的な比較結果をまとめたものである。電源波形や SPI 波形は未測定であり、原因を確定したものではない。

## 2. 調査対象

- OceanNest: `ocean_nest/OceanNest_R.kicad_sch`
- OceanNest: `ocean_nest/OceanNest_R.kicad_pcb`
- 比較対象 Keyball: `keyball39_Right_KiCad/keyball39_right.kicad_sch`
- 比較対象 Keyball: `keyball39_Right_KiCad/keyball39_right.kicad_pcb`

## 3. 確認できた事項

### 3.1 トラックボール端子の配列

OceanNest の J22 は以下の配列になっている。

| J22 ピン | 信号 |
|---:|---|
| 1 | MISO |
| 2 | MOSI |
| 3 | GND |
| 4 | VCC |
| 5 | GND |
| 6 | NCS |
| 7 | SCLK |

この配列は Keyball 系の 7 ピン接続と整合している。単純な端子順の入れ違いは見つからなかった。

### 3.2 XIAO RP2040 の SPI 接続

OceanNest では次のピンを使用している。

| 信号 | XIAO RP2040 |
|---|---|
| NCS | GPIO1 / D7 |
| SCLK | GPIO2 / D8 |
| MOSI | GPIO3 / D10 |
| MISO | GPIO4 / D9 |

これは XIAO RP2040 の SPI0 ピン構成と一致する。

### 3.3 左右判定用 GPIO0

GPIO0 / D6 は GND に固定され、左右分割キーボードの左右判定に使用されている。これは意図した回路であり、それ自体を設計ミスとはしない。

ただし、GPIO0 は GND 電源端子ではない。左右判定入力への枝線とセンサーの GND 帰還経路は、同じ GND ネットであっても物理的な電流経路を分ける必要がある。

### 3.4 本体基板上の追加コンデンサ

確認した Keyball 本体基板には、J2（BALL_PCB）用の追加デカップリングコンデンサは配置されていない。OceanNest 本体基板にも同等の追加コンデンサはない。

通常、PMW3610 センサー基板自身にはレギュレータとデカップリング部品が搭載される。同一のセンサー基板を両キーボードで差し替えて試しているため、「Keyball 本体だけにコンデンサがある」という差は今回の原因候補から除外できる。

### 3.5 GND ゾーン

KiCad PCB データを比較したところ、Keyball には GND の銅箔ゾーンが存在する。一方、OceanNest には銅箔ゾーンがなく、GND は主として 0.5 mm の配線で接続されている。

これは両基板間の明確な設計差である。

## 4. 設計上の課題

### 4.1 GND プレーンがない

PMW3610 の SPI 信号と電源電流に対する低インピーダンスの帰還経路が確保されていない。配線長が極端に長いわけではないため、GND プレーンがないだけで必ず誤動作するとは限らないが、Keyball との重要な差であり、現在の最有力候補である。

想定される影響は以下のとおり。

- SCLK、MOSI、NCS に対するリターンパスが遠くなる
- センサーの瞬間的な消費電流によってローカル GND が変動する
- SPI のしきい値に対するノイズマージンが小さくなる
- キーマトリクスなど、ほかの信号の帰還電流と経路を共有する

### 4.2 J22 の2本の GND と左右判定配線の構成

OceanNest の配線では、J22-3 側は GPIO0 の左右判定点へ、J22-5 側は XIAO の本来の GND 端子側へ配線されている。同一の `GND` ネットとして定義されているが、GND プレーンがないため、実際の低インピーダンスな共通化をセンサー基板上の GND 接続や細い配線に依存する可能性がある。

左右判定は次のような枝分かれ構成にすべきである。

```text
                  +-- GPIO0（入力、左右判定）
GND プレーン -----+
                  +-- J22-3
                  +-- J22-5
```

GPIO0 のパッドや左右判定用の枝線を、センサー電流の直列経路にしてはならない。

また、ファームウェアでは GPIO0 を入力または入力プルアップとして扱い、出力 High に設定しないことが必要である。

### 4.3 コネクタ近傍のバルク容量がない

Keyball 本体にも追加コンデンサはないため、これは Keyball との差ではない。ただし、OceanNest は GND・電源配線のインピーダンスが高い可能性があるため、J22 直近に容量を追加することは電源変動への耐性向上に有効である。

推奨候補は以下の組み合わせ。

- 100 nF セラミック
- 4.7～10 µF セラミック

センサー基板側の既存容量と重複しても、コネクタや配線によるインダクタンスの手前に配置する意味がある。

### 4.4 VCC の電圧仕様を回路図から判別できない

OceanNest の J22-4 `VCC` は XIAO RP2040 の 3V3 ではなく VBUS 側へ接続されている。したがって USB 給電時は約 5 V になる。

購入した PMW3610 基板が Keyball 互換の 5 V 入力対応品であれば問題ない。同じセンサー基板が Keyball で正常動作することから優先度は低いが、製品仕様または実測で次を確認する必要がある。

- J22-4 に許容される入力電圧
- センサー基板上のレギュレータ有無
- VDDIO のロジック電圧
- OceanNest と Keyball での実際の VCC 電圧

### 4.5 SPI 信号品質への対策余地

OceanNest の SPI 配線はおおむね十数 mm であり、長さだけを見ると極端ではない。しかし、連続した GND プレーンがないため、SCLK のエッジでリンギングやクロストークが発生する可能性がある。

次版では XIAO 側の SCLK に 22～47 Ωの直列抵抗を実装できるパターンを用意すると、信号品質の調整が容易になる。現物では SPI クロックを下げる試験でも切り分けできる。

## 5. 原因候補の優先順位

| 優先度 | 原因候補 | 根拠 |
|---:|---|---|
| 高 | GND プレーンがなく帰還経路が弱い | Keyball との明確な基板差。同じセンサーセットで結果が異なる |
| 高 | J22 の GND 配線と左右判定配線の物理的な共用 | J22-3 と J22-5 が別方向へ配線され、低インピーダンスな共通点が不明瞭 |
| 中 | センサー入力電源の変動 | PMW3610 は内部撮像・処理用電源の変動がトラッキングへ影響し得る |
| 中 | SPI 信号品質 | GND プレーンがなく、特に SCLK の帰還経路が不連続になる可能性 |
| 低～中 | ファームウェア差 | SPI 周波数、初期化、GPIO0 の設定を要確認 |
| 低 | センサー、ケース、ボールの個体・光学条件 | 同じセットが Keyball で正常動作するため優先度は下がる |

## 6. 現物での検証手順

変更は一度に一つずつ行い、各試験の前後で症状を比較する。

### 6.1 電源 OFF での導通確認

PMW3610 基板を外した状態で以下を測定する。

1. GPIO0 / D6 と XIAO GND 間
2. J22-3 と XIAO GND 間
3. J22-5 と XIAO GND 間
4. J22-3 と J22-5 間

いずれも設計上 GND なら、センサー基板を外した状態でも十分低い抵抗で接続されるべきである。センサー基板を装着したときだけ導通する場合は、センサー基板を GND ブリッジとして使用していることになる。

### 6.2 GND ジャンパー試験

J22-3、J22-5、XIAO の本来の GND 端子を短く太い線で直接接続する。

- 改善した場合: GND 経路が主因である可能性が高い
- 変化しない場合: 電源変動、SPI、ファームウェアを継続調査する

### 6.3 コンデンサ追加試験

J22 直近の VCC–GND 間に 4.7～10 µF を仮付けする。可能なら 100 nF も並列に追加する。

- GND ジャンパーだけで改善するか
- コンデンサを追加して初めて改善するか

を分けて確認する。

### 6.4 電圧測定

J22-4 と J22-5 の間を測定する。

- 静止時の電圧
- ボール操作時の電圧
- キー入力時の電圧
- Keyball 接続時との比較

オシロスコープがある場合は、J22 直近で VCC–GND 間のリップルと瞬間的な電圧低下を確認する。

### 6.5 SPI 切り分け

1. SPI クロックを現在値の 1/2 以下へ下げる
2. 改善する場合は SCLK に22～47 Ωを直列挿入する
3. オシロスコープまたはロジックアナライザで SCLK、NCS、MOSI/MISOを確認する

PMW3610 基板が3線式 SPI を内部変換している場合があるため、購入した基板の回路仕様と使用ドライバの前提も確認する。

## 7. 次版 PCB の推奨修正

1. 少なくとも片面、可能なら両面に連続した GND ゾーンを設ける
2. J22-3 と J22-5 をコネクタ直近で GND ゾーンへ接続する
3. GPIO0 は GND ゾーンから独立した短い枝線として接続する
4. J22 直近に 100 nF と 4.7～10 µF の実装場所を設ける
5. SCLK の送信元付近に 22～47 Ωの直列抵抗用フットプリントを設ける
6. SPI 配線の直下・隣接部で GND プレーンを分断しない
7. GND スティッチングビアを追加し、表裏の GND を短い間隔で接続する
8. `VCC` ではなく `VBUS_5V` または `3V3` など、実際の電圧が分かるネット名を使う
9. センサー基板を外した状態でも、左右判定と全GND端子の接続が成立するようにする

## 8. 現時点の結論

同一の PMW3610 基板・ケース・ボールが Keyball で正常動作するため、OceanNest 側の設計差を優先して調べるのが妥当である。

現時点の最有力候補は、GND プレーンがなく、J22 の2本の GND、左右判定 GPIO0、XIAO の本来の GND の間で低インピーダンスな帰還経路が確保されていないことである。ただし、静的な KiCad データだけでは原因を断定できない。

最初に行うべき試験は、J22-3、J22-5 と XIAO GND の直接ジャンパーである。その後、コネクタ直近のコンデンサ追加、SPI 低速化の順に試すことで、GND、電源、信号品質を効率よく切り分けられる。
